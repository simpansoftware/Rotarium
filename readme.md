# Rotarium
A really stupid package manager<br>
Made for Hack Club Stardance<br>
![my hackatime](https://hackatime.hackclub.com/api/v1/badge/4lvaret/simpansoftware/Rotarium)
## Features
- You can install both Python packages and native packages!
- Linux and Windows support
- You can remove your packages that you installed
- Portable!
- Online repo
- Metadata about native packages (version, general information)
- And more!
## Installation
1. Install Python 3.8 or above
2. Install venv support however you it on your Linux distro, on Windows it's included
3. Open a terminal and run ```pip install requests```. If you are on Linux, the process may be a little bit different, but do however you install requests on your distro
4. Clone the repo or download https://github.com/simpansoftware/Rotarium/releases/download/1.0.0/release.zip
5. Go into the folder that you either cloned or unzipped or whatever
6. Open a terminal in said folder
7. Run
```python installer.py```
8. It's installed! Run 
```python main.py help``` 
to see all commands
